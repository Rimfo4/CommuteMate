## 프로젝트 소개

출퇴근할 때 필요한 날씨, 경로, 할 일 같은 정보는 여러 앱에 흩어져 있습니다.

이러한 번거로움을 끝내게 해줄
통근이는 정보를 **하나의 화면**에 모으고, 사용자가 **필요한 위젯만 골라** 나만의 홈 화면을 만들 수 있게 합니다.

### 위젯

| 위젯       | 기능                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 업무 기록  | 할 일을 추가하고 완료 표시. 완료한 항목은 24시간 뒤 자동 삭제         |
| 날씨       | 현재 위치의 날씨, 온도, 습도 (기상청 API)                             |
| 알람       | 현재 시각 표시, 알람 추가·켜기/끄기·삭제, 시간이 되면 알람 울림       |
| 네비게이션 | 집·회사 주소를 기준으로 대중교통 경로 안내 (ODsay, 카카오맵 API 활용) |
| 교통량     | 주변 교통 돌발 정보 표시 (XML 더미 데이터)                            |

모든 위젯은 작은 크기와 큰 크기로 나뉘어 있어 사용자의 입맛대로 고를 수 있습니다.

## 사용한 기술

- HTML, CSS, 바닐라 JavaScript
- Custom Element (웹 기술을 활용하여 위젯을 `<weather-widget>` 같은 HTML 태그로 제작)
- localStorage (브라우저에 데이터 저장)
- 외부 API: 기상청 단기예보, ODsay 대중교통, 카카오맵
- 협업: Git/GitHub, Figma, Notion
- 배포: Vercel

통근이는 서버없이 오직 **브라우저의 localStorage**에 사용자 정보를 저장합니다.

따라 처음 실행할 때 입력한 값이 곧 계정이 됩니다.

### 테스트용 입력 값

| 화면        | 항목         | 입력 예시                                 |
| ----------- | ------------ | ----------------------------------------- |
| 사용자 확인 | 이름         | `테스트`                                  |
| 사용자 확인 | 비밀번호     | `1234`                                    |
| 주소 입력   | 집 (필수)    | `서울역`                                  |
| 주소 입력   | 회사 (필수)  | `강남역`                                  |
| 주소 입력   | 장소1 (선택) | 비워 두어도 됨, `+` 버튼으로 칸 추가 가능 |

- 이름과 비밀번호는 NOT NULL 입니다.
- 서버를 사용하지 않기에 비밀번호는 평문으로 저장합니다.
- 집과 회사는 네비게이션 위젯에서 경로를 찾을 때 사용하기에, 지도에서 검색되는 주소나 장소 이름으로 작성 부탁드립니다

### 테스트 순서

1. **사용자 확인**: 위 표의 이름과 비밀번호를 입력하고 `저장`을 누릅니다.
2. **주소 입력**: 집과 회사를 입력하고 `저장`을 누릅니다.
3. **위젯 추가**: "원하는 위젯을 추가해주세요"를 누르면 위젯 목록이 열립니다.
   - 위젯 옆 화살표를 누르면 작은 크기와 큰 크기 미리보기가 표시됩니다.
   - 누르면 선택되고, 고른 순서대로 번호가 붙습니다.
   - 한 번 더 누르면 취소합니다.
   - 아래 확인 버튼을 누르면 홈 화면으로 이동합니다.
4. **홈 화면**: 고른 위젯이 순서대로 배치되며, 하단 바가 나타납니다.
   - 하단 바 `+` : 위젯 추가 화면으로 이동 (위젯 수정)
   - 하단 바 홈 : 홈 화면으로 이동
   - 하단 바 리스트 : 장소 관리 화면으로 이동

### 위젯별 확인 방법

| 위젯       | 확인 방법                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 날씨       | 브라우저가 위치 권한을 물으면 **허용**을 눌러야 날씨가 나옵니다.                                       |
| 알람       | 알람 칸을 누르면 알람 목록이 열리고, `+` 버튼으로 시간을 정해 추가합니다. 해당 시간에 알람이 울립니다. |
| 업무 기록  | 할 일을 입력하고 추가를 누릅니다. 항목을 누르면 완료(취소선) 표시가 됩니다.                            |
| 네비게이션 | 주소 입력 화면에서 넣은 집·회사를 기준으로 경로가 나옵니다.                                            |
| 교통량     | 새로고침 버튼을 누르면 `traffic.xml`의 정보 중 기준 위치(학교) 5km 안의 돌발 정보가 나옵니다.          |

> **알람 소리가 안 날 때**
> 브라우저는 사용자가 화면을 한 번도 누르지 않은 상태에서는 소리를 막기 떄문에 화면을 눌러야합니다.

### 처음부터 다시 테스트하기

1. 개발자 도구 → **Application** 탭 → **Local Storage** → 실행 주소를 선택합니다.
2. 항목을 지우고 새로고침합니다.

| `components.css`               | 컴포넌트와 위젯 스타일                                                                                                    |

component.js에 담기엔 로직이 긴 위젯들은 따로 분류하여 파일을 나누었습니다.

## 알려진 제한 사항

- **교통량 위젯**: 경찰청 교통정보 API는 미리 등록한 IP에서만 호출할 수 있는데, 학교 네트워크에서는 고정 IP를 쓰기 어려워 실제 응답 형식에 맞춘 XML 더미 데이터를 사용합니다.
- **알람**: 웹 페이지라서 브라우저 탭이 열려 있을 때만 울립니다.
- **데이터 저장**: localStorage를 사용하므로 같은 브라우저에서만 데이터가 유지되고, 다른 기기와 공유가 되지 않습니다.
- **비밀번호**: 혼자 쓰는 앱으로 가정해 암호화 없이 평문으로 저장합니다.
